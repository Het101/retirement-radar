# Retirement Radar

Read-only scanner that matches what runs in your cloud against vendor end-of-life dates and shows the cost of doing nothing.

MVP: `npx retirement-radar scan` for AWS (EKS versions, RDS engine versions, Lambda runtimes), dates from a versioned `retirements.yaml` with source links. Nothing leaves your machine.

Later: Azure retirements, GCP, hosted weekly scans, cost per finding. ACS Chat findings link to [Threadvault](https://github.com/Het101/threadvault).
